SPICE & SERVE — Creative Restaurant Menu and Billing System
===========================================================
Features: 22 food items, creative responsive design, food search, category filters,
add-to-bill buttons, quantity controls, subtotal, 5% tax, total, print/save bill as PDF.
MySQL ki zaroorat nahi hai.

Requirements: Java JDK 17+ and Maven.

Run:
1. ZIP extract karo.
2. VS Code mein extracted SpiceAndServe-Creative folder open karo.
3. Terminal > New Terminal.
4. Command chalao: mvn spring-boot:run
5. Browser mein http://localhost:8080 kholo.

Band karne ke liye terminal mein Ctrl+C dabao.
Print bill par click karne ke baad browser print dialog mein Save as PDF choose kar sakte ho.
